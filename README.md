# ConectaNews 

## Apresentação do Projeto  

Este projeto foi desenvolvido como parte do **Trabalho de Conclusão de Curso (TCC)**, tendo como objetivo a criação de um **sistema de jornal digital** que possibilita a publicação, edição e leitura de reportagens em um ambiente web moderno e interativo.  

O sistema visa demonstrar, de forma prática, a aplicação dos conhecimentos adquiridos ao longo do curso, contemplando aspectos de **desenvolvimento web, banco de dados, usabilidade e interação com o usuário**.  

---

## Objetivos  

- Disponibilizar uma plataforma online para a publicação de reportagens jornalísticas.  
- Implementar um sistema de gerenciamento de conteúdo simples e acessível.  
- Proporcionar ao usuário uma interface amigável e responsiva.  
- Integrar recursos de interação, como comentários e fórum de discussão.  
- Aplicar boas práticas de desenvolvimento de software no contexto de um projeto acadêmico.  

---

## Justificativa  

Na Região do Vale do Itajaí não existe nenhum canal confiável e famoso, e também a falta de informações para os jovens de hoje em dia que não vão atrás de informações de qualidade e também para a facilitação dos idosos que não sabem onde buscar
informações verdadeiras e de qualidade.

---

## Funcionalidades  

- Cadastro e autenticação de usuários (administradores e leitores).  
- Publicação de reportagens com título, corpo do texto, imagens, autor e data de publicação.  
- Edição e exclusão de reportagens, usuários e comentários.  
- Exibição de reportagens mais recentes na página inicial.  
- Paginação para facilitar a navegação entre notícias.  
- Implementação de modo escuro (dark mode).  
- Fórum de discussão para interação entre leitores.  

---

## Metodologia  

O projeto foi implementado utilizando as seguintes tecnologias:  

- **Frontend**: HTML5, CSS3 e JavaScript.  
- **Backend**: PHP.  
- **Banco de Dados**: PostgreSQL.  

A metodologia adotada contempla as etapas de:  

1. Levantamento de requisitos.  
2. Modelagem do banco de dados.  
3. Implementação do backend e frontend.  
4. Testes e validações.  
5. Documentação.

---

## Resultados Esperados  

- Disponibilizar uma plataforma funcional para publicação e leitura de reportagens.  
- Demonstrar o domínio das tecnologias utilizadas no desenvolvimento web.  
- Validar a importância de soluções digitais para a área do jornalismo.
